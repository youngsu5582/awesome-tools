# EXAMPLES — 이렇게 말하면, 이렇게 나온다

가상 회사 **에이크미페이**(실재하지 않음, 가맹점 결제 승인 · 정산을 하는 B2B 핀테크)의 백엔드 공고 하나로 한 바퀴 돈다.
요청은 짧게 해도 되고 자세히 해도 된다 — 빠진 건 Claude 가 묻는다. 결과물은 앞부분만 보여 준다.

## 0. guide — 어디서 시작하지?

```text
이직 준비 시작하려고. 공고 하나 있고 이력서는 PDF 로 있어. 시험은 아직 몰라.
```

Claude 가 묻는 것 — 시험이 잡혀 있나, 결과물 폴더를 어디로 할까.
나오는 것 — 한 걸음만:

```text
intake 부터 하고 resume 으로 가면 됩니다. 시험 일정이 생기면 그때 pretest.
결과물 폴더는 ./career-next/acme-pay/ 로 할까요? (이력서가 들어가니 공개 저장소 밖을 권합니다)
```

며칠 뒤 이어서 할 때는 `지난번에 이어서` — 폴더를 읽고 "resume 1회차 보더라인, 고칠 것 3개 남음 · 시험 9일 전" 처럼 두세 줄로 말한다.

## 1. intake — 공고 정리

**짧게**
```text
이 공고 정리해줘 https://careers.example.com/acme-pay/backend
```

**자세히** — 아는 게 많을수록 묻는 게 줄어든다
```text
이 공고 정리해줘 https://careers.example.com/acme-pay/backend
백엔드 3년차, 결제 · 정산 쪽 관심. 결과물은 ~/job/acme-pay/career-next 에.
시험은 안내 메일에 75분, 코딩 1 · 주관식 5 · 서술형 2, 검색 불가라고 돼 있었어.
```

링크가 로그인 · 동적 페이지라 못 읽으면 공고 본문을 붙여 넣으면 된다.

**Claude 가 묻는 것**
- 결과물 폴더 (안 줬을 때)
- "시험 형식을 알고 있나요? (안내 메일 · 공지 · 전에 본 경험)" — 모르면 코딩만인지 · 지식 문항도 있는지 · 몇 분인지 · 언어 · 검색 가능 여부를 묻고, 답이 없는 칸은 `가정` 으로 둔다

**나오는 것** — `profile.md` 앞부분

```markdown
# 에이크미페이 · Backend Engineer
> 가맹점 결제 승인과 정산을 처리하는 서버를 만들고 운영하는 자리

## 요구 역량
| 구분 | 내용 | 출처 |
|---|---|---|
| 필수 | Java 또는 Kotlin 으로 API 개발, RDBMS 테이블 직접 설계 | 공고 |
| 필수 | 설계 의도와 엣지 케이스를 스스로 설명 | 공고 |
| 우대 | 장애 원인 분석부터 개선까지 | 공고 |

## 채용 절차와 시험 형식
절차: 서류 → 온라인 시험 → 직무 인터뷰 → 리더 인터뷰 (공고)
시험: 75분 · 코딩 1 · 주관식 5 · 서술형 2 · Java · 검색 불가
형식 출처: 지원자 기억 (안내 메일)

## 역추론 (추정)
- 승인 API 와 정산 배치가 같은 데이터를 만져서, 중복 · 순서 · 잠금 문제를 다루고 있을 것 `추정`

## 열린 질문
- 코딩 언어를 고를 수 있나 (`가정`: Java)
```

## 2. resume — 이력서 피드백

**짧게**
```text
이력서 피드백 냉정하게. 이 공고 기준으로   (+ PDF 첨부 또는 경로)
```

**자세히**
```text
~/job/resume.pdf 를 profile.md 기준으로 봐줘. 포트폴리오는 서류에 안 내. 위로는 필요 없어.
```

**이력서가 없으면**
```text
이력서가 아직 없어. 정산 배치 개선, 쿠폰 중복 발급 버그, 관리자 API 이렇게 세 개 했어.
```
→ Claude 가 항목마다 **무엇을 · 왜 · 어떻게(고른 것과 대안) · 결과 · 링크** 를 하나씩 묻고, 받은 것으로만 문장을 만든다.

**Claude 가 묻는 것**
- 「실제 한 일」 목록을 먼저 보여 주고 "이 한 줄들이 사실과 맞나요?"
- 포트폴리오 · 블로그를 서류에 같이 내는지 (내지 않으면 판정 근거로 쓰지 않는다)
- 근거가 빠진 숫자 — "불일치 0건은 어떻게 확인했나요? (주기 · 쿼리 · 기간)"

**나오는 것** — `resume/feedback.md` 앞부분

```markdown
# feedback — 1회차 (2026-11-08)

## 판정: 보더라인 — 링크와 어긋나는 주장 1개
| 질문 | 판정 | 근거 |
|---|---|---|
| ① 진짜인가 | 일부 | "재시도 정책을 고쳐 해결 - 분석 글" — 링크 글은 원인 분석까지만 있고 해결은 "다음 글에서" |
| ② 깊은가 | 설득 안 됨 | 공고 "설계 의도와 엣지 케이스" 에 해당하는 문장이 이력서에 없다 — 결과만 있다 |

잘된 것: 정산 배치 항목의 "재실행해도 같은 결과" 는 공고의 정합성 요건에 바로 닿는다 — 고치지 않는다.

## 고칠 것 우선순위
1. 링크 글과 이력서 문장 맞추기 — 해결 글을 올리거나 문장을 "원인 규명" 까지로 줄인다
2. "불일치 0건" 에 확인 방법 한 줄

## 면접 질문 후보
1. 정산 배치가 중간에 죽으면 어떤 행이 어떤 상태로 남나요? 다시 돌릴 때 두 번 반영되지 않는 이유는요?
```

`resume/draft.md` 의 Before/After 한 쌍

```markdown
- Before: 정산 배치 성능 개선 및 안정화
- After A: 하루 한 번 도는 정산 배치를 가맹점 단위로 나눠 끝난 가맹점을 표시해, 중간에 죽어도 다시 돌리면 남은 가맹점만 이어서 처리 (소요 시간 [측정 필요])
- After B: 정산 배치가 중간에 죽으면 처음부터 다시 돌며 일부 가맹점이 두 번 정산될 수 있어, 가맹점 단위 완료 표시로 재실행해도 결과가 같게 바꿈
- 이유: "개선 및 안정화" 는 누구나 쓰는 말이라 신호가 없다. 무엇을 바꿔 어떤 실패를 막았는지가 공고의 "정합성 · 엣지 케이스" 에 닿는다. 숫자는 지원자가 확인한 것만
```

## 3. pretest — 시험 대비

**짧게**
```text
시험 2주 남았어. 75분, 코딩 1 · 주관식 5 · 서술형 2, 검색 불가
```

**자세히**
```text
시험 11/22. 75분, 코딩 1 · 주관식 5 · 서술형 2, Java, 검색 · IDE 불가.
평일 하루 1시간 반. profile.md 있어.
```

**Claude 가 묻는 것** — 시험 날짜 · 하루에 쓸 시간 · 형식 중 빠진 칸

**한 바퀴**

```text
나      진단부터 해줘
Claude  주관식 12문항 → pretest/diagnostic.md (시험 화면으로 풀어도 된다)
나      (풀고) 채점해줘
Claude  ○△× 채점 → pretest/weakness.md: "Kafka 재처리 · 격리 수준에서 SQL 로 안 내려감"

나      모의고사 1회 만들어줘
Claude  별도 에이전트가 출제했습니다. 코딩 1 · 주관식 5 · 서술형 2.
        pretest/mock-1.html 을 열고 75분 동안 한 번에 푸세요.   ← 문제 내용은 말하지 않는다
나      (시험 화면에서 「최종 제출 → 답안만 복사」 한 내용을 붙여 넣고) 채점해줘
Claude  코딩 통과 · 주관식 3.5 / 5 · 서술형 13 / 20. 5항목 중 가장 낮은 건 관측.
        → pretest/review-1.html
```

붙여 넣는 답안의 모양은 [`tools/examples/answers.md`](../tools/examples/answers.md) — 시험 화면이 이 모양으로 복사해 준다 (`## N회` → `### 코딩` · `### 주관식` · `### 서술형 N` · `### 복기`).

**나오는 것** — `pretest/plan.md` 와 `scores.md` 앞부분

```markdown
## 형식
75분 · 코딩 1 · 주관식 5 · 서술형 2 · Java · 검색 불가
구간표: 훑기:3,코딩:20,주관식:25,서술형:25,제출:2

## 계획 (평일 1.5시간)
| 날짜 | 할 일 |
|---|---|
| 11/9 | 진단 12문항 + 채점 |
| 11/10~12 | 약점 영역 카드 · 서술형 유형 질문 T1 · T4 |
| 11/14 | 모의고사 1회 (75분) + 채점 |
| 11/18 | 모의고사 2회 (75분) + 채점 |
| 11/20~21 | 새 자료 없음 — 틀린 것만 · 마지막 한 장 |
```

```markdown
| 회차 | 날짜 | 코딩 | 주관식 | 서술형 | 5항목 평균 (전제 · 문제 · 선택 · 실패 · 관측) | 다음 회차에 고칠 것 |
|---|---|---|---|---|---|---|
| 1 | 11/14 | 통과 | 3.5 | 13 | 1.5 · 1.5 · 1.5 · 1 · 0.5 | 서술형마다 "무엇을 어떤 기준으로 보나" 한 문단 |
```

**형식을 모를 때 · 바뀔 때**
```text
시험이 있다는데 형식은 몰라           → 흔한 구성으로 시작, 칸마다 `가정`
형식 나왔어. 코딩만 3문항, 90분이래  → 다음 회차부터 코딩 3문항 시험 화면, 서술형 연습은 계획에서 뺀다
```

## 4. interview — 기술 면접

**짧게**
```text
다음 주 수요일 직무 인터뷰야. 60분, 실무자 둘이래
```

**자세히**
```text
11/26 직무 인터뷰, 60분, 실무자 2명, 라이브 코딩 없음. profile.md 랑 resume/feedback.md 있어.
모의 면접은 ChatGPT 음성 모드로 볼 거야.
```

**Claude 가 묻는 것** — 형식 중 빠진 칸(시간 · 면접관 · 라이브 코딩), 대표 경험 3개를 이걸로 할지, 그리고 경험마다 30초 · 2분 답을 **직접 써 달라는 것** (대신 써 주지 않는다)

**한 바퀴**

```text
나      대표 경험 30초 · 2분 답 써 봤어 (붙여 넣기)
Claude  정산 배치: L3(중간에 죽으면)까지는 답에 있고 L4(다시 한다면 · 무엇을 보고 있나)가 비어 있습니다.
        이 답이 부를 꼬리 질문: "완료 표시와 정산 결과 저장이 다른 트랜잭션이면 어떻게 되나요?"
        → interview/stories.md

나      모의 면접 준비물 만들어줘
Claude  → interview/brief-1.md (이력서 요약 · 다룰 주제 · 진행 규칙. 질문 문장은 넣지 않았습니다)
        ChatGPT 음성 모드 새 대화에 붙여 보내고, 음성으로 바꿔 45분 보세요.

나      (끝나고 앱의 대화 기록을 그대로 붙여 넣고) 채점해줘
Claude  9문항 · 5축 평균 결론 먼저 1.2 · 정확성 1.6 · 깊이 1.1 · 근거 1.3 · 솔직함 1.8.
        멈춘 단: 지원자가 L3 에서 4번. 면접관(음성 AI)이 꼬리 없이 넘어간 곳 2번 — 규칙 위반, 감점 아님.
        → interview/mock-1.md · scores.md
```

## 5. 해 주지 않는 것

```text
지금 시험 보는 중인데 이 문제 풀어줘        → 거절, 시험이 끝난 뒤를 제안
지금 면접 중인데 이 질문 답 바로 만들어줘    → 거절, 면접이 끝난 뒤 회고를 제안
작년 기출 모아 둔 링크로 모의고사 만들어줘  → 기출 공유 자료는 쓰지 않는다, 공고의 스택 · 업무 영역으로 출제를 제안
이력서 그냥 전부 다시 써줘                  → 통째 대필 대신 항목별로 고를 수 있는 수정안
```
