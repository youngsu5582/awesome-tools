# 모의고사 문제 파일 형식

`tools/build_mock_sheet.py` 가 정규식으로 읽는 모양이다. 예시: [`tools/examples/mock.md`](../tools/examples/mock.md)

```markdown
# 모의고사 N회                          ← 첫 줄. "N회" 의 숫자가 회차가 된다

## 코딩 (20분)                           ← 괄호 안 분 = 코딩 권장 시간 (문항이 여러 개면 아래 「코딩 여러 문항」)
**「문제 이름」** — 설명 한두 줄. 외부 문제면 [「문제 이름」](https://…) 처럼 링크를 단다

## 주관식 (25분 · 문항당 5분 · ①②③ 각각 한두 줄)   ← "문항당 N분" = 문항 권장 시간

### 1. 문항 제목
**상황** — 코드 · SQL · 숫자로 구체적인 장면

**묻는 것**
1. …                                    ← 번호 목록 = 답 칸 ①②③
2. …
3. …

**보려는 것** — 무엇을 보는지 (정답을 흘리지 않게)

## 서술형 (25분 · 문항당 12분 · 전제 → 문제 → 선택 → 실패 → 관측)   ← 마지막 "·" 뒤가 쓰는 순서 안내

**서술형 1. 문항 제목.**
상황 · 숫자 · 관찰 지표 → 무엇을 쓰라는 요구

---
```

## 코딩 여러 문항

코딩 절 안에 `### 제목` 하위 제목을 달면 하위 제목마다 한 문항이다. 하위 제목이 없으면 지금처럼 절 전체가 한 문항이다. 예시: [`tools/examples/mock-coding-only.md`](../tools/examples/mock-coding-only.md)

```markdown
## 코딩 (60분 · 문항당 20분)             ← 괄호 안 분 = 코딩 전체, "문항당 N분" = 문항 권장 시간

### 1. 문제 이름                          ← 제목 앞 "1." 같은 번호는 떼고 읽는다 (문항 번호는 쓴 순서)
설명 한두 줄. 링크가 있으면 본문에 `[이름](https://…)` 로 단다
첫 `###` 앞에 쓴 글은 공통 설명으로 모든 문항 앞에 붙는다

### 2. 다음 문제 이름
…
```

- **권장 시간**: 절 머리 `(N분)` = 코딩 전체. `문항당 N분` 이 있으면 그 값, 없으면 전체 ÷ 문항 수 (나누어떨어지지 않으면 소수 첫째 자리). 머리에 아무것도 없으면 전체를 20분으로 본다.
- 문항마다 탭 · 결과 · 통과 수 · 메모 · 코드 칸 · 링크(있으면)가 따로 생긴다.
- 답 복사 머리: 한 문항이면 `### 코딩`, 여러 문항이면 `### 코딩 1`, `### 코딩 2` …

## 절은 골라 쓴다

- 코딩 · 주관식 · 서술형 절은 각각 있어도 없어도 되지만 **하나 이상**은 있어야 한다. 코딩만 3문항인 시험, 주관식만 있는 진단지(예시: [`tools/examples/diagnostic.md`](../tools/examples/diagnostic.md))도 된다.
- 없는 절은 탭 · 시작 화면 문구 · 답 복사 · 시간 기록표 · 채점 화면에서 통째로 빠진다.
- 주관식 문항마다 `**묻는 것**` 아래 번호 목록이 있어야 한다 (답 칸 개수가 된다).

## 구간표

구간(훑기 · 코딩 · 주관식 · 서술형 · 제출)은 문제 파일이 아니라 `--schedule "훑기:3,코딩:20,…"` 로 준다.

- 주지 않으면 `훑기 · (문제 파일에 있는 절) · 제출` 로 만든다. 시간은 절 머리 `(N분)`, 없으면 훑기 3 · 코딩 20 · 주관식 25 · 서술형 25 · 제출 2.
- 구간표에 문제 파일에 없는 절 이름(예: 서술형이 없는데 `서술형:25`)이 있으면 경고를 출력하고 그 구간을 뺀 채 계속한다.
- 문제 파일에 있는 절이 구간표에 없으면 오류로 멈춘다.
- `훑기` · `제출` 은 빼도 된다 (예: 진단지 `주관식:15,제출:1`). `훑기` 를 빼면 훑기 탭은 권장 시간 없이 문제 목록만 보여 준다. 실전 대비라면 `제출` 은 빼지 않는다 — 빈 칸을 확인하는 구간이다.

## 답 복사의 코드 블록

답을 복사하면 코드는 펜스로 감싼다. 펜스 언어는 `--lang` (기본: 비어 있음 = 언어 없는 펜스). 채점 화면 생성기는 펜스 언어가 무엇이든(없어도) 읽는다.
