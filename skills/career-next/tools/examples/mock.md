# 모의고사 1회 (예시)

## 코딩 (20분)

**「두 수의 합」** — 정수 배열 `nums` 와 정수 `target` 이 주어진다. 합이 `target` 인 두 원소의 인덱스를 작은 것부터 담은 배열을 돌려준다. 답은 정확히 하나다. (`nums` 길이 ≤ 100,000)

## 주관식 (10분 · 문항당 5분 · ①②③ 각각 한두 줄)

### 1. 같은 키를 두 번 넣은 HashMap

**상황**

```java
Map<String, Integer> m = new HashMap<>();
Integer first = m.put("a", 1);
Integer second = m.put("a", 2);
```

**묻는 것**
1. `m.get("a")` 의 값과 `m.size()` 를 각각 쓴다.
2. `first` 와 `second` 에는 무엇이 들어 있나?
3. 키가 **없을 때만** 넣으려면 어떤 메서드를 쓰나?

**보려는 것** — `put` 이 덮어쓰고 이전 값을 돌려준다는 걸 아는지.

### 2. 함수로 감싼 조건

**상황** — `users.email` 에 B-tree 인덱스가 있다.

```sql
SELECT * FROM users WHERE LOWER(email) = 'a@b.com';
```

**묻는 것**
1. 이 쿼리는 `email` 인덱스로 시작점을 바로 찾을 수 있나? 왜?
2. SQL 을 그대로 두고 빠르게 만드는 방법 하나.
3. 그 방법의 대가 하나.

**보려는 것** — 인덱스의 정렬 순서와 조건의 모양을 연결하는지.

## 서술형 (12분 · 문항당 12분 · 전제 → 문제 → 선택 → 실패 → 관측)

**서술형 1. 두 번 결제되는 주문.**
결제 API 응답이 늦으면 앱이 같은 요청을 한 번 더 보내고, 그래서 결제가 두 번 된 적이 있다. 하루 주문은 10만 건이다.
같은 요청이 여러 번 와도 한 번만 결제되게 하는 설계와, 결제 결과를 모를 때의 처리를 쓰라.
