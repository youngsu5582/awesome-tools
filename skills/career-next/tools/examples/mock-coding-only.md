# 코딩 모의고사 1회 (예시)

## 코딩 (60분 · 문항당 20분)

### 1. 두 수의 합

정수 배열 `nums` 와 정수 `target` 이 주어진다. 합이 `target` 인 두 원소의 인덱스를 담은 배열을 돌려준다. 답은 정확히 하나다. 링크: [「두 수의 합」](https://leetcode.com/problems/two-sum/)

### 2. 유효한 괄호

`(` `)` `{` `}` `[` `]` 로만 이루어진 문자열이 올바르게 열리고 닫혔는지 판정한다. 같은 종류로 닫아야 하고, 열린 순서의 반대로 닫아야 한다.

### 3. 문자열 뒤집기

문자 배열 `s` 를 제자리에서(추가 배열 없이) 뒤집는다.
